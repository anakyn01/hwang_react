Asychronus Code

비동기 코드를 사용하면 프로그램이 (파일에서 데이터를 가져오는 것과 같이) 
시간이 오래 걸리는 작업을 시작하고 
첫 번째 작업이 완료되기 전에 다른 작업을 계속 진행할 수 있습니다.
애플리케이션이 멈추는 것을 방지하는데, 이는 사용자 경험에 매우 중요합니다.

일부 작업은 완료하는 데 시간이 걸립니다 (네트워크 요청, 타이머, 사용자 입력).
반응성을 유지하기 위해 JavaScript는 비동기 프로그래밍을 사용할 수 있습니다 .
비동기 흐름이란 자바스크립트에서 특정 작업이 백그라운드에서 
실행 되고 결과가 준비되면 처리 될 수 있도록 하는 방식을 말합니다 .

멈춘 페이지는 깨진 페이지입니다.
비동기 코드는 실행을 차단하지 않습니다.

자바스크립트는 서로 다른 핵심 개념을 사용하여 비동기 프로그래밍을 처리합니다.
- Synchronus : 표준 흐름이 한 줄씩 실행
- Timers : 다른 코드가 대기하는 동안 코드가 실행될 수 있도록 합니다
- Callbacks : 비동기 자바스크립트를 위한 최초의 해결책
- Events : 실행 대기 중인 콜백 함수를 저장
- Promises : 비동기 작업을 깔끔하게 처리하는 도구
- Async/Await : 비동기 코드를 처리하는 깔끔하고 현대적인 방법

병렬처리 : 서로다른프로세서에서 여러 작업을 동시에 수행 [더빠르게 완료]
멀티프로세서 하번에 10,000개의 이미지를 처리

비동기 처리 : 동시에 실행하는 것이 아니라 작업간 전환 []
프로세서 1개 사용자가 스크롤하는 동안 코드실행
지금 이작업을 시작하세요 나는 결과를 즉시 알필요는 없어요
완료되면 나중에 알려주세요

레스토랑에서 음식을 주문할때
1.음식주문(비동기 호출)
2.요리사가 요리하는동안 앉아서 다른일을 하세요
3.서버가 음식을 가져와요(콜백)


제어 흐름

- 프로그램에서 명령문이 실행되는 순서
- 자바스크립트는 코드를 위에서 아래로 , 왼쪽에서 오른쪽으로 실행합니다.
- 자바스크립트는 인터프리터 언어입니다 코드를 한줄씩 실행합니다
- 함수는 정의된 순서가 아니라 호출된순서로 지정됨
