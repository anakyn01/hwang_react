methods

- length() : 문자열의 길이
- charAt() : 지정된 문자열에서 지정된 인덱스 문자를 리턴
- charCodeAt() : 지정된 문자열에서 지정된 인덱스 문자코드(utf-16[0 ~65535])를 리턴
- concat() : 두개 이상의 문자열을 연결
- 문자열 부분 추출
slice(start, end) substring(start, end) substr(start, length)
- toUpperCase() : 대문자로 - toLowerCase() : 소문자로 - isWellFormed() : 문자열의 형식이 올바른지 판단(true, false) - trim() : 문자열에 양쪽 긑에 공백을 제거 - padStart() : 문자열에 시작부분에 패딩을 추가 - padEnd() : 끝나는 부분에 페딩을 추가 - replace() : 문자열에서 지정된 값을 다른 값으로 바꾼다
