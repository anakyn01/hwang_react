python : list,tuple,dic,set
자바스크립트에 세트
- new Set()
- 빈집합을 생성하고 이를 사용하여 add()값을 추가
- 중복을 허용하지 않는다 고유한

Method

- has() : 지정된 값이 집합에 존재 하는지?
- forEach() : 각요소에 대해서 호출
- values() : 값들
- keys() : 세트와 맵을 호환하기 위함
- entries() : [값, 값]
- union() : 두 집합의 합집합
- difference() : 두 집합간의 차이
- intersection() : 두 집합의 교집합
- symmetricDifference() : 두 집합간의 대칭 차이
- isDisjointFrom() : 공통되는 요소가 없으면 true 있으면 false
- isSubsetOf() : 이집합의 모든요소사 인자 집합의 요소와 동일한지 비교
- isSupersetOf() : true인자 집합이 모든 요소가 이집합에도 포함되어 있는지 여부 반환
